# Focus WEB

**Умный персональный планировщик задач с прогнозом продуктивности (ML)**

Клиентская часть ВКР: одностраничное приложение на **React** + **TypeScript** + **Vite**, обращение к **Focus API** по REST.

## Требования

- **Node.js** 20+ (LTS)
- Запущенный **Focus API** (см. репозиторий бэкенда), по умолчанию ожидается `http://localhost:5032`

## Настройка

Скопируйте переменные окружения (при необходимости):

```bash
cp .env.example .env
```

| Режим | `VITE_API_BASE_URL` |
|--------|---------------------|
| Разработка с **прокси Vite** (по умолчанию) | `/api/v1` — браузер ходит на тот же origin, Vite проксирует `/api` → API |
| Фронт без прокси (другой хост/порт) | `http://localhost:5032/api/v1` (или URL вашего сервера) |

Прокси задаётся в `vite.config.ts` (`target: http://localhost:5032`). При смене порта API обновите `target`.

Если фронт и API на **разных origin**, на бэкенде нужен **CORS** для origin dev-сервера (например `http://localhost:5173`).

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется по адресу из консоли Vite (обычно `http://localhost:5173`).

Сборка и локальный просмотр production-артефактов:

```bash
npm run build
npm run preview
```

## Аутентификация

1. **Регистрация**: `POST /api/v1/Auth/register`  
   ```json
   {"email": "user@example.com", "password": "pass123", "displayName": "Имя"}
   ```

2. **Вход**: `POST /api/v1/Auth/login`  
   ```json
   {"email": "user@example.com", "password": "pass123"}
   ```

3. В ответе приходит `accessToken`. Клиент сохраняет его и для защищённых запросов отправляет заголовок:  
   ```
   Authorization: Bearer <accessToken>
   ```

*(На ASP.NET Core маршруты часто нечувствительны к регистру; в таблице ниже для краткости указаны пути в нижнем регистре — эквивалентны контракту API.)*

## Эндпоинты (используемые фронтом)

| Метод | Путь | Описание |
|-------|------|----------|
| POST | /api/v1/Auth/register | Регистрация |
| POST | /api/v1/Auth/login | Вход |
| GET | /api/v1/Tasks | Список задач (`from`, `to` — опционально) |
| GET | /api/v1/Tasks/{id} | Задача по ID |
| POST | /api/v1/Tasks | Создать задачу |
| PUT | /api/v1/Tasks/{id} | Обновить задачу |
| DELETE | /api/v1/Tasks/{id} | Удалить задачу |
| POST | /api/v1/Schedule | Сгенерировать расписание на дату |
| GET | /api/v1/daily-notes/{date} | Заметка за день (`yyyy-MM-dd`) |
| POST | /api/v1/daily-notes/{date} | Создать/обновить заметку |

Подробные DTO и enum’ы — в `src/types/api.ts` и в README **Focus API**.

## Структура проекта

| Путь | Назначение |
|------|------------|
| `src/App.tsx` | Маршрутизация |
| `src/api/` | HTTP-клиент и вызовы API |
| `src/types/api.ts` | Типы ответов/тел запросов |
| `src/context/AuthContext.tsx` | Сессия пользователя |
| `src/pages/` | Экраны (задачи, дневник, расписание, вход) |
| `src/components/` | Общий layout и защищённые маршруты |
| `src/lib/` | Утилиты (даты, подписи приоритетов/статусов) |
